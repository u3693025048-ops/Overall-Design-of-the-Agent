**A 域核心公式**

| 公式 | 含义 |
|------|------|
| $a_m = N V_c \dot\lambda$ | PN 基本律（TPN 用 $V_c$，PPN 用 $V_m$） |
| $\ddot\lambda = -(2-N)\frac{V_c}{R}\dot\lambda + \frac{a_t}{R}$ | 稳定性条件，**N>2 是红线**（已仿真验证） |
| $a_{cmd} = N'V_c\dot\lambda + \frac{N'}{2}a_T$ | APNG（$N'/2$ 来自 LQR，保证常值机动零脱靶） |
| $ZEM = \frac{V_c t_{go}^2}{2}\dot\lambda$ | 零控脱靶量 |
| $N_{opt} = 3$ | LQR 综合型指标的最优导航比（符号推导见 verify_lqr_pn.py） |
| $a_M = a_T \cdot N/(N-2)$ | 稳态需用过载 — **随 N 单调下降**（「N 大费过载」并不总成立） |

**综合演示的四个标定结论**（`run_all.py --demo`，与卡片经验一致）：

1. **N 扫描呈 U 型**：最优 N≈6（内点）——注意这不是 LQR 的 3，因为叠加了延迟+噪声+机动
2. **延迟有门槛**：τ≤100 ms 可忽略，150 ms 起恶化（0.09 m），300 ms 崩到 7.52 m
3. **λ̇ 滤波器 τ_f 存在最优**：5 ms（边界值，提示扫描范围需下探）
4. **MC 验收**：均值 0.121 m 评级优秀，但 σ/μ=0.51 鲁棒性需改进

**五条不可违背的建模约定**（详见 `algorithms/README.md`）：
λ̇ 符号定义 · 碰撞三角初始化 · 噪声必须走「角度+微分」路径 · 延迟用解析解不用前向差分 · MC 按分位数验收

## 五、核心代码与仿真验证

### 1. 弹道仿真 v3（`verify_engagement.py` · 纯标准库 math + numpy/matplotlib 统计绘图）

**8 面板联合验证**（`verify_engagement.png`），8 项判据全部 ✅：

| 验证组 | 关键结论 |
|--------|---------|
| ⓪ 理想工况 | 碰撞三角初始化 ⇒ 脱靶 1.6e-14 m，仿真器自洽（v1 误用纯追踪给出 0.51 m） |
| ①A 机动 | N∈[2.5,8]，末段 9g：脱靶单调↓至 0.000 m，**N 越大对 a_t 抑制越强** |
| ①B 噪声 | 测角 σ_λ=1 mrad + 一阶滤波微分：脱靶 0.069→0.274 m 单调↑，**N 是噪声放大器** |
| ①B2 滤波器 | τ_f∈[5,200] ms：最优 20 ms（3.45→0.25→0.34 m）— 印证 A-卡06 |
| ①C 工程合成 | 9g + τ=100 ms + σ_λ=1 mrad：**U 型，最优 N=5.0**（7.47→0.226→0.60 m） |
| ② N>2 红线 | 注入 3° 航向误差：N=1.5 发散、N=2 持平、N=3,4 衰减（与符号一致） |
| ③ 延迟门槛 | N=4，τ=0/50/100/150/200/300 ms：τ≤50 无碍，τ=300 恶化到 7.50 m |
| ④ APN | 受限工况（12g/20g/τ=100ms）：APN 0.063m << PN 6.492m；误差 100% 退化到 5.438 m |
| ⑤ BPN 框架角 | K_bias 0→5：终端框架角 10.19°→8.06° 单调压低，**代价是过载**（K_bias ≤ N/3） |
| ⑥ 蒙特卡洛 | 200 次：均值 1.05 m，**P95 = 3.56 m（3.4×）** — 必须按分位数验收 |

**四条超出原书经验的发现**（已写入脚本结尾）：

1. 「N 大费过载」不总成立：稳态需用过载 $a_M = a_T\cdot N/(N-2)$ 随 N 下降
2. N_opt=3 的真正来源是 LQR 控制能量权重，**而非**对目标机动的补偿
3. 「N 放大噪声」机理专属角度噪声经微分后的蓝谱；直接在 λ̇ 上叠平谱噪声会得出相反结论
4. λ̇ 滤波器存在最优时间常数（≈20 ms），**过度滤波同样有害**

### 2. LQR 符号推导（`verify_lqr_pn.py` · SymPy）

- 推导 1D LQR Riccati 闭合解 ⇒ 解析给出 N_opt=3
- 符号验证 LOS 动力学 $\ddot\lambda = (2-N)(V_c/R)\dot\lambda + a_t/R$（含原书第 5 章 `−(2−N)` 符号校勘）
- 推导稳态需用过载 $a_M = a_T\cdot N/(N-2)$

## 七、核心工程经验速查

- **N 调参口诀**：从 N=3 起试；过载大降 2.5，脱靶量大升 4；按舵机延迟修正（0ms→3.5~4.0，100ms→2.8~3.2，200ms→2.5~3.0）
- **延迟是头号杀手**：本工况 τ≤50ms 无碍，τ=300ms 脱靶 7.5 m（**7.5 万倍**）；N·τ/t_go→1 是判据
- **限幅要「双限」**：幅值 + 速率；留 20~30% 过载裕度；**λ̇ 绝不能差分，必须滤波**（τ_f 最优 20 ms）
- **APN 的性能上限 = 目标加速度估计精度**：误差 >50% 时反不如 PN，须加置信度门限退化
- **别只看均值**：某项目均值 3.2 m、实弹打 28 m，**P95 才是命门**（本仿真 P95/均值 = 3.4）
- **BPN 偏置有代价**：框架角压低 K_bias↑，但过载也↑；经验上限 K_bias ≤ N/3
- **导引头噪声建模**：必须用「测角 + 滤波微分」（蓝谱）才能复现「N 放大噪声」；平谱速率噪声模型会给出相反结论
- **碰撞三角初始化**：导弹初速必须落在碰撞三角上，否则「零控」不零（v1 bug ⇒ 0.51 m 假脱靶）

cd ../../_tools
