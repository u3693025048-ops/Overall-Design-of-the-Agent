# 数据资产 05 — 设计与仿真检查清单

> 把 30 张卡的【A++ - 经验】段反写成**可勾选的检查项**，覆盖从建模到验收的完整链路。
> 用法：每个阶段结束前逐条过一遍；任一项 ❌ 不得进入下一阶段。
> 标注 ⚠️ 的是"作者明确踩过的坑"，属高优先级。

---

## 阶段 1：需求与建模

- [ ] ⚠️ **执行机构延迟已进模型**再开始调参（`B-02`：LQR 仿真完美、上硬件就抖，根因是延迟未建模）
- [ ] ⚠️ **过载限幅保留 20%~30% 裕度**（`A-04`：按 80% 设计，靶试时需求冲到 85%）
- [ ] 明确是否带不等式约束：只要有界就必须用 PMP，变分法解不了（`B-01`）
- [ ] 终端约束数量最小化——每加一个都可能丢掉解析解（`B-01`）
- [ ] 三维问题**分解到两个正交平面**，不要硬推三维方程（`A-03`）
- [ ] 坐标变换写成独立函数（`euler2dcm()` / `dcm_transform()`），不散落在主程序（`A-03`）
- [ ] PP/TPN 的**指令方向**已显式标注（三本书存在命名矛盾，以方向而非缩写为准）（`A-01`）

## 阶段 2：制导律设计

- [ ] $N$ 按**回路延迟**选型：0 ms→3.5~4.0；50 ms→3.0~3.5；100 ms→2.8~3.2；200 ms→2.5~3.0（`A-02`）
- [ ] PP N 与 TPN 的 $N$ 未混用（PPN 需 6~10，TPN 3~5）（`A-01`）
- [ ] $N$ 已限幅在 $[3,10]$；$t_{go}$ 很大时增益负值已强制置 3（`B-02`）
- [ ] 若用变导航比：时间常数 0.2~0.5 s，**无阶跃切换**，自适应增益 $K$ 不过大（`A-02`）
- [ ] 若用 APN：估计误差 <30% 才启用，>50% 退化为 PN；估计延迟 <0.2 s（`A-05`, `B-03`）
- [ ] 若用 APN：**有置信度门限与退化路径**（不加门限是常见翻车点）（`A-05`）
- [ ] 目标高频机动（~2 Hz）场景已确认 APN 是否反而更差（`A-05`）
- [ ] 若带终端角约束：最优 $N$ 已按终端角重新标定（`C` 域）

## 阶段 3：状态估计

- [ ] ⚠️ **$\dot\lambda$ 没有用直接差分**——已滤波或卡尔曼估计（`A-01`：差分使指令"抖得像筛子"）
- [ ] $\dot\lambda$ 滤波器时间常数已扫描（本工况最优 ≈20 ms，不是越小越好）（仿真标定）
- [ ] 导引头模型用**测角噪声 + 滤波微分**，而非在 $\dot\lambda$ 上直接叠噪声（后者会得出反向结论）（仿真标定）
- [ ] 目标机动模型已按机动强度选型（CV/CA → Singer → 当前统计 → IMM）（`B-03`）
- [ ] Singer $\alpha$ 按目标类型取值：客机 0.1~0.5 / 战斗机 0.5~2.0 / 规避导弹 2.0~10.0（`B-03`）
- [ ] 卡尔曼调参顺序 **先 R → 后 Q → 再 $P_0$**，$P_0\approx10R$（`A-05`）
- [ ] 机动检测阈值不过严（建议 99.5%），未导致滤波器频繁重置（`B-03`）
- [ ] 若用 IMM：模型集覆盖实际机动模式，且转移概率已标定（`B-03`）

## 阶段 4：最优控制（LQR / OGL）

- [ ] $Q,R$ 初值按 **Bryson 规则**设定，量级可比（`B-02`）
- [ ] $Q_{22}\approx10\,Q_{11}$（角速率权重大于角度权重）（`B-02`）
- [ ] $R$ **不是零矩阵**（$R$ 正定是控制有界的关键）（`B-02`）
- [ ] 有限时域用**瞬态解**（Riccati 从 $t_f$ 反向积分），非稳态解（`B-02`）
- [ ] $P$ 矩阵特征值全正（不正定 → 反馈律发散）（`B-02`）
- [ ] $S$ 在 $10\sim100R$，**未盲目取大**（过大使末端控制量剧烈抖动）（`B-02`）
- [ ] $t_{go}$ 已限幅 $[0.1,10]$ s + 一阶低通（$\tau\approx0.05$ s）（`B-02`）
- [ ] "冻结系数"近似已通过仿真验证（`B-02`）
- [ ] 在线算力评估过：不够则离线增益表 + 在线插值（`B-02`）

## 阶段 5：仿真实现

- [ ] **LOS 角速率符号正确**：$\dot\lambda = (r_y V_{rel,x} - r_x V_{rel,y})/r^2$（符号反 → 导弹被推开）
- [ ] **初速按碰撞三角设定**（否则理想工况也有 0.5 m 级假脱靶）
- [ ] 有 `miss_event` 终止条件（否则 $N=2$ 会爆步数）
- [ ] **目标机动已进入目标运动学**（常见 bug：机动只喂给 APN 补偿项，目标仍在直飞）
- [ ] 框架角按 $|\lambda-\gamma_M|$ 定义，且**只在 $r>150$ m 的制导段统计**（末端尖峰无物理意义）
- [ ] 舵机延迟用解析离散解 $a(t+dt)=a_{cmd}+(a(t)-a_{cmd})e^{-dt/\tau}$
- [ ] **场景有鉴别力**：已确认"改变参数时指标会动"（否则所有工况都是 0.000 m 的假成功）
- [ ] 噪声用 AR(1) 有色噪声（$\phi=e^{-dt/\tau}$），统计特性与 $dt$ 无关
- [ ] 数值变量已归一化 / 缩放（位置与协态量级悬殊时必做）（`B-04`）

## 阶段 6：蒙特卡洛与验收

- [ ] 蒙特卡洛 **≥500~1000 次**，覆盖边界工况（`B-05`）
- [ ] 同时报告 **均值 / RMS / P95 / CEP**，不只看均值
- [ ] 脱靶量 <1 m 优秀 / 1~3 m 良好 / 3~5 m 及格（`B-05`）
- [ ] 鲁棒性 $\sigma/\mu$ <0.3 优秀 / 0.3~0.5 良好 / >0.5 需改进（`B-05`）
- [ ] 带干扰脱靶均值 ≤ 理想值 2 倍；>3 倍必须回炉（`B-05`）
- [ ] **过载未超限**（脱靶达标但过载超限 = 方案不可行）
- [ ] 框架角未超视场、末段未失锁
- [ ] 延迟扫描已做（判据 $N\tau/t_{go}\to1$ 的失稳门槛已定位）

## 阶段 7：工程落地

- [ ] ⚠️ **"仿真完美、实物抖动"类问题已排查**：过载裕度 / $S$ 过大 / 延迟未建模（三项高频根因）
- [ ] 定点化采用**混合精度**：大范围量浮点，姿态角/制导系数 Q15（`B-05`）
- [ ] 融合架构**首次从串行入手**（`A-06`）
- [ ] 若用模糊：规则表 ≤5×5，前期先模糊验证、后期再上网络（`A-06`）
- [ ] 若用 MPC：预测时域 10~20 步、硬约束加松弛、算力已实测（`A-06`）
- [ ] 若协同：通信时延 ≤控制周期 1/5；一致性有参考节点拉到正确值（`B-06`）
- [ ] 任务分配含"覆盖度"约束 + "切换代价"惩罚（`B-06`）
- [ ] 半实物（HIL）验证已做——仿真扫参只是中间步（`A-02` 三步定 N 的第三步）

## 速查：仿真结论与教科书矛盾时的三步诊断

1. **独立复算**——另写一份最简实现（如显式欧拉）对拍，确认量级无误，排除代码错。
2. **查场景鉴别力**——若所有工况结果恒等（如脱靶全为 0.000 m），是场景太容易，不是代码问题。
3. **查模型简化**——若趋势与教科书相反，先怀疑被省略的环节（如"N 放大噪声"的真正来源是角度噪声经微分变蓝谱；直接在 $\dot\lambda$ 上叠平谱噪声会得出相反结论）。
