# 数据资产 04 — 工程参数速查表

> 从 30 张卡【A++ - 经验】段中提炼的**可直接落地的数值**，全部标注出处卡号（可回查 `03_heuristics.md` / `assets.json`）。
> 用法：初值照抄「推荐值」→ 按「调节方向」微调 → 用「红线」校验是否越界。

## 1. 制导律参数

| 参数 | 推荐值 | 调节方向 | 红线 / 失效边界 | 出处 |
|---|---|---|---|---|
| 导航比 $N$（TPN） | **3.5**（初选），扫 $2.5\sim5.0$ | 延迟大 → 调小；机动强 → 调大 | $N\le2$ 不收敛；$N>10$ 易饱和 | A-01, A-02, B-02 |
| 导航比 $N$（PPN） | $6\sim10$ | 同效果需比 TPN 大 2 倍左右 | 直接套 TPN 的 $N$ 脱靶量大数倍 | A-01 |
| $N$ 随舵机延迟选型 | 0 ms→**3.5~4.0**｜50 ms→3.0~3.5｜100 ms→2.8~3.2｜200 ms→2.5~3.0 | 延迟↑ ⇒ $N$↓ | 不确定延迟时取 $N=3.0$ | A-02 |
| $N$ 限幅域 | $[3,\ 10]$ | 初始段 $t_{go}$ 很大时增益可能算成负值 → 强制置 3 | <3 不稳，>10 饱和 | B-02 |
| APN 补偿系数 | $N/2$（对常值机动零脱靶） | $N$ 取 4~6（建议 **4.5**） | 估计误差 >30% 时 APN 可能不如 PN；>50% 反而更差 | B-03, A-05 |
| APN 估计延迟上限 | **≤0.2 s** | 越小越好 | >0.2 s 补偿"帮倒忙" | B-03 |
| 变导航比时间常数 | $0.2\sim0.5$ s | 禁止阶跃切换（指令跳变、弹体抖动） | 自适应律增益 $K$ 过大 → 系统震荡 | A-02 |
| BPN 偏置 / 切换滞回 | $t_{go}$：进 3~5 s / 退 4~6 s（退比进大 1~2 s）；$\hat a_T$：进 3~5 g / 退 2~4 g（退比进小 1~2 g） | 必须滞回 | 无滞回 → PN/PG 来回震荡 | A-06 |

## 2. 目标机动建模与估计

| 参数 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| Singer 机动频率 $\alpha$ | 缓慢（客机）**0.1~0.5**｜中等（战斗机巡航）**0.5~2.0**｜剧烈（导弹规避）**2.0~10.0** 1/s | 模型选择比滤波器更重要："先花 70% 精力建模型" | B-03 |
| 机动检测置信度 | **99.5%**（一般 95% 或 99%） | 阈值过严 → 滤波器频繁重置、估计反而更差 | B-03 |
| 估计误差门限 | 误差超 **50%~60%** 时 APNG 劣于 PNG | 必须加置信度门限，低于阈值退化为 PN | A-05 |
| 卡尔曼调参顺序 | **先 R → 后 Q → 再 $P_0$**；$P_0 \approx 10R$ | $Q$ 对角元设太小（如 0.01）→ 估计滞后 0.3 s | A-05 |
| 目标机动模型选型 | 匀速/匀加速 → Singer（一阶马尔可夫）→ 当前统计 → IMM | 模型永远比滤波器重要 | B-03 |

## 3. 最优控制 / LQR

| 参数 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| 权重初值（Bryson 规则） | $Q_{ii}=1/x_{max,i}^2$，$R_{jj}=1/u_{max,j}^2$ | 保证状态与控制量级可比，避免数值问题 | B-02 |
| $Q$ 内部比例 | **$Q_{22} \approx 10\,Q_{11}$**（角速率权重 >> 角度权重） | 脱靶量主要由角速率决定；反着设"弹道抖得像蛇" | B-02 |
| 实测可用配置 | $Q=\mathrm{diag}([1,100])$、$R=10$ → 脱靶 <0.5 m、最大过载 <8 g | 可作为基线 | B-02 |
| 终端权 $S$ | $S \approx 10\sim100\,R$（先固定 $s\approx100$） | **$S$ 不是越大越好**：过大使末端控制量剧烈变化（仿真完美、实物抖动） | B-02 |
| $q/r$ 起始比例 | 从 **10** 开始试 | 先固定 $s$，再调 $q/r$ | B-02 |
| Riccati 求解 | 有限时域用**瞬态解**（从 $t_f$ 反向积分） | 稳态解（ARE）只保证无限时间最优，初始瞬态可能很差 | B-02 |
| $P$ 矩阵校验 | 特征值必须全正 | 不正定 → 反馈律直接发散 | B-02 |
| 在线性算力不足时 | 离线算增益表 + 在线查表插值（或每 0.01 s 重解一次） | 某型导弹实测实时性无问题 | B-02 |

## 4. $t_{go}$（剩余飞行时间）

| 项目 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| 限幅 | $[0.1,\ 10]$ s | 目标大机动时 $t_{go}$ 可从 2 s 跳到 4 s，指令剧烈震荡 | B-02 |
| 滤波 | 一阶低通，$\tau \approx 0.05$ s | **必须加滤波** | B-02 |
| 机动修正 | $t_{go} = R/V_c + 0.5\,a_{T,est}\,t_{go}^2/V_c$，迭代 **2~3 次** | 隐式方程 | B-02 |
| 定位 | **全系统最容易出问题的地方** | 优先排查项 | B-02 |

## 5. 导引头 / 噪声 / 视场

| 参数 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| $\dot\lambda$ 获取 | **禁止直接差分**，须滤波或卡尔曼估计 | 差分使噪声放大数倍、指令"抖得像筛子" | A-01 |
| $\lambdȧ$ 滤波时间常数 $\tau_f$ | **~20 ms 为内点最优**（本仿真标定：5 ms→3.45 m，10 ms→0.96 m，**20 ms→0.25 m**，50 ms→0.27 m，100 ms→0.39 m，200 ms→0.34 m） | 太小≈纯差分噪声爆炸；太大引入相位滞后 | 仿真标定（book010/verify_engagement.py B2 组） |
| 噪声模型选择 | **测角噪声 $\sigma_\lambda$ + 滤波微分** | 直接在 $\dot\lambda$ 上叠平谱噪声会得出"N 大反而好"的错误结论 | 仿真标定 |
| 测角噪声量级 | $\sigma_\lambda \sim 1$ mrad（示例工况） | $\sigma_\lambda$ ≥3 mrad 时 $\tau_f$=20 ms 会把指令打饱和（>25 g） | 仿真标定 |
| 视场半角 / 框架角 | 典型视场半角 **30°**；框架角按 $|\lambda-\gamma_M|$ 定义，仅统计 $r>150$ m 的制导段 | 误用 $\arccos(\hat v\cdot\hat r)$ 会算出 175° 的荒谬值 | 仿真标定 |

## 6. 执行机构与延迟

| 项目 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| 过载限幅裕度 | 保留 **20%（作者建议 30%）** | 某项目按 80% 可用过载设计，靶试时需求冲到 85% | A-04 |
| 限幅方式 | 软限幅 $u_{sat}=u_{max}\tanh(u/u_{max})$ 优于硬限幅；动态限幅最推荐 | — | A-04 |
| 抗饱和三层次 | ① 指令限幅 → ② 抗饱和制导律（条件积分 / 反计算 $K_{aw}=1/K_i$）→ ③ 动态补偿 | 实测饱和次数 -60%、脱靶 5 m→1.2 m | A-04 |
| 舵机延迟门槛 | **τ ≤50 ms 基本无碍**；100 ms→脱靶 0.0045 m；150 ms→0.093 m；200 ms→1.364 m；300 ms→7.50 m | 判据 $N\tau/t_{go}\to1$ 失稳 | 仿真标定 |
| 协同通信时延 | ≤ 控制周期的 **1/5**（周期 50 ms → 时延 ≤10 ms） | 时延 10 ms→50 ms，收敛时间 2 s→8 s | B-06 |
| 建模顺序 | **执行机构延迟必须先进模型再调参** | LQR 仿真完美、上硬件就抖，查出是延迟未建模 | B-02 |

## 8. 数值方法 / 工程实现

| 项目 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| 变量缩放 | 全部归一化到 $[0,1]$ 或 $[-1,1]$ | 位置 $10^4$ m 与协态 $10^{-3}$ 不缩放，数值误差淹没真解 | B-04 |
| 协态初值猜测 | ① 从终端反推 ② 按物理意义给量级 ③ 先简化一维 → 最后用 GA 辅助 | "从终端反推屡试不爽" | B-04 |
| CasADi | 优先 **MX** 变量；**不做缩放**（须先自行归一化）；初值用**线性插值** | 状态量级差异大（1000 vs 0.01）时 IPOPT 收敛极慢 | B-04 |
| HJI 维度 | 状态 >4 维网格爆炸 → 用**稀疏网格** | 6 维跑一晚无结果 | B-03 |
| 神经网络近似 | 1~2 隐藏层、每层 8~16 神经元、ReLU；输出层 sigmoid | 边界震荡 → 用物理约束（过载/速率限幅）作激活函数；训练数据须覆盖"危险区域" | B-03, A-06 |
| 模糊规则表规模 | **5×5 足够**（9×9 会规则冲突、输出不稳） | 先模糊验证，性能瓶颈再上网络 | A-06 |
| 坐标变换 | 写成独立函数（`euler2dcm()`）；三维**分解到两个正交平面**分别用二维方程 | 三维不要硬推 | A-03 |
| 融合架构 | **第一次做融合先从串行入手**（最稳） | 并行响应快但融合决策难；混合性能最优但验证复杂 | A-06 |

## 9. 协同制导

| 项目 | 推荐值 | 说明 | 出处 |
|---|---|---|---|
| 一致性陷阱 | 一致性只保证"一致"，不保证"一致到正确值" | 所有弹预计到达时间都偏大 → 收敛后仍偏大，须引入参考节点/外部输入 | B-06 |
| 期望攻击时间 | 必须在 **[最小可达时间, 最大可达时间]** 区间内取值 | 否则赶不上或需绕大圈超出机动范围 | B-06 |
| 任务分配 | 加"覆盖度"约束防"就近分配"局部最优；结果频繁切换时加"切换代价"惩罚 | 目标分配与航迹规划是**迭代关系**而非串行 | B-06 |
| 航迹安全裕度 | 设**最大绕飞系数**，超限重新分配目标 | 时间错开但风速扰动 → 交叉点险撞 | B-06 |
| 人工势场局部极小 | 弹间距离在某范围波动超 **3 s** → 给一枚加随机方向短时推力 | 否则两弹僵持不动 | B-06 |

