# 审稿意见 R2 处置方式（不公开 GitHub）

针对 Reviewer #1 第 5 条：代码与数据改为 **期刊 Supplementary ZIP 随修订稿上传**，不使用 GitHub。

## 一、回复口径（已写入英文回复信）

- 不提供公开仓库。
- 审稿人/编辑通过期刊系统下载 ZIP。
- 写明：交战条件 `.mat` 是按发表的麻雀级参数与固定种子 **仿真生成** 的，不是实装遥测。
- 写明：GSMultiAgent 主表 AND 使用了运行期 bootstrap 补种（1 真 MATLAB seed + 2 填充）；独立优化器与单智能体为 3 次真 MATLAB。文稿 §4.1 已披露，不再把 1–22 与 225 写成同一单位。ZIP 内 `config.yaml` 仍默认关掉 fill，便于审稿人按三真种子复现，与已发表 GSM 格子不是同一条执行路径。

中文可对编辑说一句：因单位数据管理要求，源代码与复现数据以补充材料打包提交，不另建公开代码托管。

## 二、抽样合成数据怎么处理

本地其实有三类“合成”，处置不同。

| 类别 | 是什么 | 能否进主表 | 能否进 ZIP |
|------|--------|------------|------------|
| A. 外部 MC 初值 `.mat` | `mc_data_generator.py` 按 master seed 抽样生成的交战扰动（T1–T4，dev/test 分离） | 可以（这是论文协议本身） | **要进**：生成器 + `seed_map.json` + 主实验用到的 `.mat`（T1–T4，seed 42/43/44） |
| B. 运行期 bootstrap 补种 | `mc_and_bootstrap_fill`：只实跑第一个 seed，其余两条用该次弹道再抽样填记录 | **GSM 已发表表用了**；主文须写明，且 MC 次数不可与 75×3 真 MATLAB 对读 | **代码可带**。ZIP `config.yaml` 仍 `false`（审稿人按三真种子复现）。已发表 GSM 格子不要假装是三真种子 |
| C. 事后补样本 CSV | `collect_and_simulate_seeds.py`、`gsm_all_seeds_incl_simulated.csv`、`simulated/` | **不能** | **不打进 ZIP**。若需自留，放本机 `exploratory_not_in_paper/`，补充材料说明里写一句“未用于报告结果” |

原则：审稿人拿到的包应能 **按固定种子重生 A 类数据**，并看到主表对应的真实 runs；B/C 不得伪装成独立复现。

## 三、ZIP 应包含 / 必须剔除

**包含**

- 源码：`multi_agent/`、`experiments/`、`knowledge_base/`、`cli_agent.py`、`requirements.txt`
- 去密钥后的 `config.yaml`（`api_key` 全部改为 `YOUR_API_KEY`）
- `REPRODUCIBILITY.md`、`experiments/README.md`、`SUPPLEMENT.md`
- `data/mc/` 中 T1–T4、master 42/43/44 的 dev/test `.mat` 与 `seed_map.json`
- 主表用 CSV（不含 `_is_simulated=True` 的行）
- `experiments/equal_mc_budget.py`（等预算协议）

**剔除**

- 任何 `api_key`、`.env`、`scripts/.gsm_ssh_pass`
- `chroma_db/`、`__pycache__/`、`.git/`、IDE 缓存
- `outOfDate/`（过程脚本、旧输出、重复说明）
- `DATA/run_archives/`、大日志、Ubuntu pull 缓存
- `*_incl_simulated.csv`、`simulated/`、`gsm_all_simulated.csv`
- 注释里的示例密钥（打包时一并脱敏）

## 四、操作步骤

1. Word `papers.docx` 的 Data Availability 已改为 Supplementary ZIP（不要写 GitHub）。若需重跑补丁：`python scripts/patch_paper_data_availability.py`。
2. 本地工作区当前可能没有现成 `data/mc/*.mat`（生成物未入库）。打包脚本会按固定种子 **现场生成 A 类** `.mat` 写入 ZIP，不依赖本机已有文件。也可先手动生成：

   ```powershell
   python experiments/mc_data_generator.py --output-root data/mc --n-runs 100 --no-broadside
   ```

3. 运行打包（脱敏配置、关掉 bootstrap 补种、排除合成 CSV）：

   ```powershell
   python scripts/pack_supplement.py
   ```

   输出默认：
   - 可投稿文件夹：`paper_revision/GSMultiAgent_submit/`（每次打包重建）
   - 期刊上传 ZIP：`paper_revision/GSMultiAgent_supplement.zip`
   先前解压对照副本已归档到 `outOfDate/paper_extracts/GSMultiAgent_submit/`。
4. 解压抽查：`config.yaml` 无真实密钥且 `mc_and_bootstrap_fill: false`；无 `incl_simulated`；有 `data/mc/T1` 等；`REPRODUCIBILITY.md` 与 `SUPPLEMENT.md` 在根目录。
5. 将 ZIP 作为期刊 Supplementary file 上传；Cover letter / 回复信用 `paper_revision/reviewer1_round2_response.md`。
6. 等预算主表已定稿：Random **8/12**、CMA-ES **12/12**、Direct PPO **11/12**（`results/experiment_plan/table5_equal_mc.csv`）。旧不等预算表已迁到 `outOfDate/`。
