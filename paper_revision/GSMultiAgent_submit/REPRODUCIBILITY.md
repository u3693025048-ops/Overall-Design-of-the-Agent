## Equal Monte Carlo budget

Every method is capped at the same maximum number of development Monte Carlo
calls (Reviewer #1, round 2):

| Quantity | Value | Source |
|----------|------:|--------|
| Outer iterations | 5 | `workflow.max_iterations` |
| PPO episodes / outer iteration | 15 | `matlab_rl_optimizer.max_episodes` |
| Development seeds per candidate | 3 | `{1,2,3}` offsets |
| Search trajectories per MC call | 10 | `mc_search_n_runs` when `mc_tiered_eval` |
| Test / final trajectories | 100 | `mc_final_n_runs` / CLI `n_runs` |
| **Max candidate evaluations** | **75** | `5 × 15` |
| **Max development MC calls** | **225** | `75 × 3` (ceiling, not identical accounting) |

Random Search / CMA-ES / Direct PPO count **one MATLAB invocation per development seed** (3 per candidate). GSMultiAgent’s tabulated 1 / 7 / 22 values are **outer-loop derived** and typically execute one real MATLAB seed with bootstrap fill of the other two; they are not interchangeable with 225. Search uses 10 trajectories; test uses 100.

Post-hoc from baseline JSON `history` (first `dev.all_pass`, each candidate = 3 calls): Random **73.9** (8/12 found), CMA-ES **79.2** (12/12), Direct PPO **54.0** (11/12). File: `results/experiment_plan/optimizer_equal_mc_75/first_success_mc_calls.csv`.

CMA-ES uses λ = 4 + ⌊3 ln d⌋ = 10, but generations are **not** a budget unit.
Search stops when 75 candidates (225 MC calls) have been evaluated. A truncated
final generation is scored and does not update the covariance.

Code: `experiments/equal_mc_budget.py`.

## Simulated Monte Carlo files

`data/mc/*.mat` are synthetic engagement initial conditions generated by
`experiments/mc_data_generator.py` from published Sparrow-class parameters and
fixed seeds. They are not flight recordings. GSMultiAgent tabulated AND used
runtime bootstrap fill (`mc_and_bootstrap_fill`: one real MATLAB seed, two
filled). Random Search / CMA-ES / Direct PPO / Single-Agent used three real
MATLAB seeds per candidate. Bootstrap-filled extra seeds are not stored as
separate `.mat` files in this archive.

## PPO probability ratio (Eq. 30)

Implementation (`multi_agent.rl.matlab_rl_optimizer.ppo_probability_ratio`):

```
r_t(θ) = exp( clip( log π_θ(a|s) − log π_{θ_old}(a|s), −10, 10 ) )
```

The clip on the log-difference is overflow protection only. The PPO surrogate
then clips `r_t` to `[1−ε, 1+ε]`.
