# Supplementary material

This archive accompanies the revised manuscript. It is **not** a public
GitHub repository.

## What is included

- Source code for GSMultiAgent, baselines, and the experiment runners
- `experiments/mc_data_generator.py` and the T1–T4 Monte Carlo `.mat` files
  used for master seeds 42, 43, and 44 (development offsets 1–3, test 4–6)
- `REPRODUCIBILITY.md`: API model IDs, MATLAB version, experimental dates,
  and the equal Monte Carlo budget (maximum 225 development MC calls)
- Result CSVs that correspond to **real** simulation runs only.
  Open `results/experiment_plan/gsm_all_seeds.csv` for every GSMultiAgent
  ablation row (E0/E1/E2/E3, order, optimization, correction, model
  substitution) in one table. Equal-budget baselines remain in
  `optimizer_equal_mc_75/`. Aligned Single-Agent (search 10, test 100) is
  `optimizer_equal_mc_75_sah_n10/` (12/12 first success, development, and test).
  The superseded 100-trajectory SAH archive stays in
  `optimizer_equal_mc_75_sah/` and is not packed.

## Simulated engagement data (not flight recordings)

Files under `data/mc/` are **synthetic initial conditions**: they are sampled
from the published Sparrow-class (AIM-7F) parameter table and the scenario
dispersions in the paper, with a fixed RNG seed per file. They can be
regenerated by

```
python experiments/mc_data_generator.py --output-root data/mc --n-runs 100 --no-broadside
```

using the same master seeds. No recorded missile telemetry is included.

## What is excluded on purpose

- API keys and credentials
- Separate `.mat` files for bootstrap-filled extra seeds
- Post-hoc resampled result rows (`*_incl_simulated.csv` and similar)
- Large run archives and vector-database caches

GSMultiAgent tabulated AND used runtime bootstrap fill (one real MATLAB seed,
two filled). Random Search / CMA-ES / Direct PPO / Single-Agent used three
real MATLAB seeds per candidate. Post-hoc `*_incl_simulated.csv` rows do not
appear in the reported tables. Tabulated MC-call integers are not in identical
units; see `REPRODUCIBILITY.md`.

## Equal Monte Carlo budget

All methods share a **ceiling** of 75 candidate evaluations × 3 development
seeds = 225 development Monte Carlo calls. That ceiling is not a claim that
tabulated MC integers use the same accounting. Search uses 10 trajectories;
test uses 100. CMA-ES is capped on candidate count, not on the number of
generations. See `experiments/equal_mc_budget.py`.

Equal-budget run archives:

- `results/experiment_plan/optimizer_equal_mc_75/` — Random Search, CMA-ES, Direct PPO (36 JSON runs)
- `results/experiment_plan/optimizer_equal_mc_75_sah_n10/` — Single-Agent, search 10 / test 100 (12 JSON runs; first success 12/12)
- `results/experiment_plan/table5_equal_mc.csv` — pooled Table 5: GSM 9/12·5/12; Random 8/12; CMA-ES 12/12; Direct PPO 11/12; SAH n10 12/12
- `results/experiment_plan/table6_equal_mc.csv` — Single-Agent Table 6 means (MC 135–225; Time/call ≈ 0.06 min)
