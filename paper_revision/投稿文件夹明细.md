## 四、可提交的试验数据

### 4.1 协议内交战初值 `data/mc/`（73 文件，约 0.19 MB）

**性质：** 仿真抽样初值，不是实装遥测。由 `mc_data_generator.py` 按固定种子生成，可重生。

| 项 | 数量 / 规则 |
|----|-------------|
| 场景 | T1、T2、T3、T4 |
| 主种子 | 42、43、44 |
| 每个主种子 | 开发集 offset 1–3 → `seed_{master*100+offset}_dev.mat`；测试集 offset 4–6 → `*_test.mat` |
| `.mat` 合计 | **72**（4×3×6） |
| `seed_map.json` | 种子与路径对照 |

重生示例：

```
python experiments/mc_data_generator.py --output-root data/mc --n-runs 100 --no-broadside
```
